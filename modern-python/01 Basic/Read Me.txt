1. All the notes are made on Jupyter Notebook Editor. To access these files should have jupyter notebook installed on your system.

2. Most of the files uploaded will be in .rar format i.e, zipped format. To unzip you can use softwares likes winrar or 7zip etc.

3. To download jupyter notebook:
- Either Install 'Anaconda software' from where you will get jupyter notebook and python/DS/ML useful libraries preinstalled.
- Or go to system cmd and type:

pip install jupyter

It will download and install jupyter notebook automatically to on your system.

4. To view my .ipynb files:
a) After installing jupyter notebook, in system cmd type:

jupyter notebook

b) It will automatically launch the jupyter notebook on your default browser. Then browse to the required folder where you have downloaded my files.
c) click on the .ipynb file.
